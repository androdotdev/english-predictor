# 📚 English CEFR Predictor

A machine learning project that predicts the **CEFR English writing level** of a text sample.

The project compares multiple classification algorithms using TF-IDF text features and evaluates their performance across six CEFR levels:

**A1, A2, B1, B2, C1, C2**

## 🎯 Objective

The goal is to investigate how well traditional machine learning algorithms can classify English writing according to CEFR level based only on the written text.

The project was developed as part of a classification algorithm evaluation exercise.

## 📊 Dataset

The dataset contains English writing samples labelled with CEFR levels:

- A1
- A2
- B1
- B2
- C1
- C2

The main input feature is the **text itself**, while the target variable is the corresponding CEFR level.

Because the model primarily relies on textual information, the project also investigates some of the limitations of using raw text as the only feature.

## 🔧 Preprocessing

The text was converted into numerical features using **TF-IDF (Term Frequency–Inverse Document Frequency)**.

The vectorizer was fitted only on the training data:

```python
vectorizer = TfidfVectorizer()

x_train_vectorized = vectorizer.fit_transform(x_train)
x_test_vectorized = vectorizer.transform(x_test)
```

This prevents information from the test set from being used during training.

## 🤖 Models

Three classification algorithms were evaluated:

1. **Linear Support Vector Classifier (LinearSVC)**
2. **K-Nearest Neighbors (KNN)**
3. **Decision Tree**

All three models were evaluated using the same TF-IDF representation to make the comparison fair.

## 📈 Results

| Model | Accuracy | Macro F1 | Weighted F1 |
|---|---:|---:|---:|
| **Linear SVC** | **0.59** | **0.57** | **0.58** |
| KNN | 0.48 | 0.46 | 0.48 |
| Decision Tree | 0.41 | 0.40 | 0.41 |

### Linear SVC — Per-Class Performance

| CEFR Level | Precision | Recall | F1 |
|---|---:|---:|---:|
| A1 | 0.76 | 0.88 | 0.82 |
| A2 | 0.69 | 0.65 | 0.67 |
| B1 | 0.46 | 0.27 | 0.34 |
| B2 | 0.48 | 0.54 | 0.51 |
| C1 | 0.41 | 0.52 | 0.46 |
| C2 | 0.73 | 0.55 | 0.63 |

Overall accuracy was **59%**, with a macro F1-score of **0.57**.

## 🔍 Findings

### Linear SVC performed best

Linear SVC substantially outperformed both KNN and the Decision Tree.

This is likely related to the nature of the input data. TF-IDF produces a high-dimensional and sparse representation of text, which is generally well suited to linear classifiers.

### Performance varies considerably between CEFR levels

The model performed particularly well on **A1**, with an F1-score of 0.82.

However, **B1** was much more difficult to classify, with an F1-score of only 0.34.

The model also showed weaker performance on B1, B2 and C1 compared with the lower and highest levels.

### Text-only features have limitations

Inspection of the Linear SVC coefficients showed that some classes were strongly associated with particular words, names, topics, or entities.

For example, some highly weighted features included names, locations, organizations, historical figures, and topic-specific vocabulary.

This suggests that the model may be learning **dataset-specific lexical patterns** rather than purely learning linguistic properties associated with CEFR proficiency.

This also helps explain some unexpected predictions during manual testing.

## 🧪 Manual Testing

Several manually written examples were tested to investigate whether the model was primarily relying on text length.

Changing the length of otherwise similar texts did not consistently change the prediction.

However, texts containing more sophisticated vocabulary sometimes produced unexpected predictions, including lower CEFR classifications.

This suggests that the model is not simply measuring text length and that the dataset's vocabulary/topic patterns may have a significant influence on predictions.

## ⚠️ Limitations

The main limitation is that the model currently relies almost entirely on the text representation generated by TF-IDF.

CEFR proficiency involves more than vocabulary frequency. Important linguistic characteristics can include:

- sentence structure
- grammatical complexity
- vocabulary diversity
- word and sentence length
- use of complex connectors
- syntactic complexity
- spelling and grammatical errors

These characteristics are not explicitly represented in the current model.

Another limitation is that some classes are substantially harder to distinguish than others, particularly the intermediate levels.

## 🚀 Future Improvements

Possible improvements include:

- Add numerical linguistic features such as average word length and sentence length.
- Add vocabulary diversity measures.
- Add grammatical and syntactic complexity features.
- Experiment with word and character n-grams.
- Compare additional models such as Logistic Regression or Naive Bayes.
- Perform hyperparameter tuning.
- Investigate class balance.
- Analyze the confusion matrix to understand which CEFR levels are commonly confused.
- Use a larger and more linguistically representative dataset.
- Investigate whether topic-specific vocabulary is creating unwanted shortcuts.

## 🌐 Streamlit Application

The trained Linear SVC model and TF-IDF vectorizer are saved and used by a Streamlit application.

The application allows a user to enter an English writing sample and receive a predicted CEFR level.

## 📌 Conclusion

Among the three tested algorithms, **Linear SVC was the strongest model**, achieving 59% accuracy and a macro F1-score of 0.57.

The experiment demonstrates that traditional machine learning can extract useful information from English writing using TF-IDF, but also highlights the limitations of using lexical features alone for CEFR classification.

The most important finding is that improving this system likely requires **better linguistic features and/or a more representative dataset**, rather than simply switching between basic classification algorithms.
